## Project Overview

- Framework: Next js (app router)
- Language: Typescript
- Styling: Tailwind and Shadcn UI
- ORM: Prisma
- Database: NeonDB

## Commands

- Dev server: bun dev
- Build: bun build
- Lint: bun lint

## Project structure

`app/`: Routes app router
`api/`: Routes for Instagram API, podcast fetch, and Instagram API cron task
`components/`: Shared components
`content/`: Texts contents for site sections and components
`lib/`: Data for misc sections of the site, functions to fetch data from Instagram, and Prisma handler
`prisma/`: Database schemes
`public/`: Assets for the site
